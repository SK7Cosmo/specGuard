# SpecGuard

**Built doesn't mean fulfilled.**

SpecGuard is an evidence-driven software verification platform for finding gaps between original software requirements and the implementation that was built.

This repository is at project initialization. It contains planning, governance, and evidence-recording structure only; application functionality and completed verification work are not yet claimed.

## Project framework

The project is organized around eight lifecycle stages: Understand, Specify, Plan, Design, Implement, Verify, Review, and Automate. Each stage has a separate evidence directory under `codex-evidence/`.

- [Goals and principles](GOALS.md)
- [Milestone plan](PLANS.md)
- [Agent and contributor guidance](AGENTS.md)
- [Evidence index](codex-evidence/EVIDENCE_INDEX.md)
- [Model strategy and records](codex-evidence/models/MODEL_STRATEGY.md)

Initialization only. No application functionality, test results, benchmark results, or model usage records are asserted by this scaffold.
