# Milestone plan

This plan is a framework, not a claim that any milestone has been completed. Keep each milestone bounded, reviewable, and tied to evidence.

| Milestone | Lifecycle stage(s) | Intended outcome | Status |
|---|---|---|---|
| M0: Initialize repository | Understand, Plan | Establish project guidance, goals, plans, and evidence framework | In progress |
| M1: Understand the problem | Understand | Capture users, context, assumptions, risks, and source evidence | Not started |
| M2: Define requirements | Specify | Establish authorized, traceable functional and quality requirements | Not started |
| M3: Plan and design | Plan, Design | Select bounded scope and document architecture and decisions | Not started |
| M4: Implement a vertical slice | Implement | Build approved functionality with critical paths developed test-first | Not started |
| M5: Verify and review | Verify, Review | Evaluate requirement coverage, quality, and security with evidence | Not started |
| M6: Automate repeatable checks | Automate | Automate approved deterministic checks and evidence capture | Not started |

Update statuses only when the work has actually occurred. Record scope changes and obtain authorization before changing requirements.
