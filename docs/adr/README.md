# Architecture decision records

Store one decision per file. Suggested naming: `NNNN-short-title.md`.

- [0001 — Local audit operating boundary](0001-audit-operating-boundary.md): approved SG-02 product boundary.
- [0002 — Milestone-driven development baseline](0002-milestone-driven-development-baseline.md): product-owner-authorized SG-03A revision to development constraints and SG-03 finding disposition.
- [SG-03B Design decision register](SG-03B-design-decision-register.md) lists open M3 decisions and required evidence.
- [SG-03D secret-handling decision](SG-03D-secret-handling-decision.md) records the product-owner rejection and resubmission policy.
- [SG-03D mandatory M3 conditions](SG-03D-m3-mandatory-conditions.md) lists Design deliverables, validation evidence and progression gates.
- [SG-04A proposed architecture boundaries and evidence authority](SG-04A-architecture-boundaries.md) is a proposed ADR for product-owner review; it does not close M3 conditions or select deferred technical dependencies.
- The SG-04D addendum to [SG-04A architecture boundaries](SG-04A-architecture-boundaries.md) records the normative verdict-policy correction and design-contract clarifications; it remains proposed and leaves D01–D12 open.
