# Model experiments

Use this file to record controlled model comparisons. No experiments have been run as part of repository initialization.

For each experiment, record:

- Experiment ID, date, and question being evaluated.
- Bounded task and fixed input/prompt, including relevant version or hash when available.
- Models and reasoning efforts actually used, plus availability constraints.
- Evaluation method and criteria, including deterministic checks where applicable.
- Observed results, validation outcomes, duration, and resource use when observable.
- Limitations, conclusion, and follow-up.

Do not invent missing measurements or present uncontrolled observations as comparable results.
